# Codex Skill Packaging

This folder contains a Codex skill bundle for Memory Map.

## Install
1) Ensure skills are enabled in Codex (see README).
2) Copy this file to your Codex skills directory:

```
~/.codex/skills/memory-map/SKILL.md
```

3) Restart Codex.

## Usage
Invoke the skill by name in chat:
```
$memory-map-init
```
