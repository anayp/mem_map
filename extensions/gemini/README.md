# Gemini CLI Extension: Memory Map

This extension provides context and tools for interacting with the Memory Map system via Gemini CLI.

## Installation

To use this extension, you can include this `GEMINI.md` in your context or session.

## Usage

Once loaded, you can ask Gemini to:
- **"Initialize Memory Map"**: Creates the necessary `mem_map` folder structure.
- **"Start Memory Map Server"**: Launches the visualization UI.
- **"Update Context"**: Edits the `context-data.json`.
- **"Scan Directory"**: Updates the graph based on current files.

## Files

- `GEMINI.md`: The system prompt / context definition.
